### System Overview
Designed and implemented the core real-time processing engine and graphical user interface for professional cart-based and handheld clinical ultrasound systems.

### Key Technical Contributions
*   **High-Performance Pipeline:** Developed low-latency acquisition and rendering pipelines using C++ and CUDA, ensuring deterministic frame rates for intensive, multi-modal workflows.
*   **Imaging Modalities:** Implemented end-to-end processing pipelines for B-mode, Anatomical/Curved M-mode, Color/Power Doppler, Pulsed-Wave (PW), and Continuous-Wave (CW).
*   **Versatile Scanning:** Optimized synchronization for diverse transducer geometries, including Linear, Convex, and Phased-Array arrays.
*   **Clinical Connectivity:** Integrated DICOM networking (Worklist, Store, Print) and cross-platform mobile interfaces compliant with medical device standards.
